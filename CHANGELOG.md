# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-05-14

### Added
- Initial release
- Support for Claude Opus 4.6, Sonnet 4.6, and Haiku 4.5 models
- Text generation with Anthropic-compatible message format
- Tool use and function calling support
- Structured outputs with JSON schemas
- AWS SigV4 request signing via AWS SDK for PHP
- Admin settings page for credential configuration
- PHP constant overrides for containerized deployments
- Authentication restoration hook for WordPress AI Client compatibility
